# DiabloIIToolbox 内存指针与功能指针获取链路

> 适用环境：暗黑破坏神 2 原版（非 D2R），进程 `D2Loader.exe`，mod `anhei2mapBUS`（`-locale kor`），1.13c。
> 全部读取为**只读**（OpenProcess `PROCESS_QUERY_INFORMATION | PROCESS_VM_READ` + ReadProcessMemory），不写入、不注入。
> 地址分两类：**模块偏移**（跨会话稳定）与**会话级绝对地址**（重启即变，必须重定位）。

---

## 0. 模块基址与会话约定

| 模块 | 会话示例基址 | 说明 |
|---|---|---|
| D2Loader.exe | 进程本体 | 启动器按此进程名取 PID |
| D2CLIENT.dll | `0x6FAB0000` | 玩家/背包/物品/仓库 |
| D2Common.dll | `0x6FD50000` | 数据表（sgptDataTables） |
| D2WIN.dll | `0x6F8E0000` | 控件链/单机选中 |
| D2Lang.dll | `0x024F0000` | GetLocaleText/文本表 |
| Fog.dll | `0x6FF50000` | 界面标记 |
| D2MCPClient.dll | — | 战网账号/角色表 |
| d2launch.dll | — | 人物位置索引/战网选择 |

> 基址每次会话可能不同（ASLR 关闭下通常固定），一律用 `module_base(pid, "模块名")` 现取，**不得硬编码**。

**地址可靠性原则**：所有偏移来自 CE 实测 / d2hackmap 1.13c 源码（`D2CallStub.cpp`、`d2structs.h`、`d2ptrs.h`）/ 反汇编确认；会话级地址经权威链路运行时重定位并回写 json 缓存。

## 1. 人物 / 背包 / 物品链

### 1.1 人物对象链

```
[ D2CLIENT.dll + 0x11B800 ]  →  pPlayer（Player 结构）
    +0x60  →  pInv（UnitInventory）
    +0x14  →  人物名称（UTF-8/ANSI 字符串，deref_str）
```

- 配置：`1.13c.json` "人物指针"（dword）、"人物名称"（string, len 10, deref_str）。
- 用途：一切物品/背包/仓库遍历的入口。

### 1.2 背包物品链（UnitInventory 链表）

```
pPlayer + 0x60  →  pInv（UnitInventory）
    +0x00  dword 印章 = 0x01020304（未进游戏/非背包时为其他值 → 判空）
    +0x0C  →  pFirstItem
    +0x10  →  pLastItem
pFirstItem → UnitAny 链表（每节点一件物品）：
    +0x00  dwUnitType（=4）
    +0x04  dwTxtFileNo（= 码表 id = ItemTxt 行号）
    +0x14  →  pItemData
    +0x2C  →  pInvItem（格子位置结构，见 1.4）
    next   = [pItemData + 0x64]（pNextInvItem）
```

### 1.3 ItemData 字段

| 偏移 | 字段 | 说明 |
|---|---|---|
| +0x00 | dwQuality | 1灰 2白 3白粗 4蓝 5**套装** 6黄 7**暗金** 8橙 |
| +0x28 | dwFileIndex | quality 5 → SetItemsTxt 行号；quality 7 → UniqueItemsTxt 行号 |
| +0x45 | nItemLocation | 0 背包 / 3 盒子 / 4 仓库 |
| +0x64 | pNextInvItem | 链表 next |
| +0x69 | nLocation | 2 腰带 / 3 装备 |

### 1.4 物品位置结构（pInvItem，格子坐标）

```
UnitAny + 0x2C → pInvItem
    +0x0C  gx（格列）
    +0x10  gy（格行）
```

### 1.5 容器与面板

| 面板 | 尺寸（列×行） | 第一格客户区坐标（面板基准） | 格步长 |
|---|---|---|---|
| 背包 | 10×4 | (857, 541) | 29px（格 28 + 间隔 1） |
| 仓库 | 10×10 | (538, 370) | 29px |
| 盒子 | 10×8 | — | 29px |

> 基准坐标通过"鼠标悬停物品反推第一格"校准（`_sort_panel.py PANELS`）。

## 2. 页面 / 状态标记

### 2.1 界面标记（页面识别）

```
[ Fog.dll + 0x4AFE0 ]  →  ui 标记指针
    +0x8   dword 界面标记
```

语义（mod 实测）：
- `10 / 11`：战网大厅
- `2xxx`（2 开头四位数）：战网界面（角色选择等）
- `3xxx`（3 开头四位数）：**游戏中**；此时**物品码表已加载**，可获取码表
- 单机模式标记不含账号信息（前端不显示账号）

### 2.2 游戏类型

```
[ D2Client.dll + 0x11C394 ]  dword   0=单机(SP)  3=战网加入(BNet Join)
```

### 2.3 仓库 / 盒子开关

```
[ D2CLIENT.dll + 0x50D00 ]  →  ui 指针
    +0x60  dword 仓库开（1=开）
    +0x64  dword 盒子开
```

- 容器类型速查：`[ D2CLIENT.dll + 0x11BC34 ]` 12=仓库 14=盒子。

### 2.4 仓库页签结构（当前页数）

**AOB 定位（首选）**：全内存搜特征串
```
FF 00 00 00 01 01 00 00 68 67 6C 20
```
结构地址 = 命中地址 − 0x10，校验 `_stash_struct_ok`（+0x00 总页数 1-100 且 +0x04 文本缓冲指针首 dword 0-100）：

```
stash_page_struct:
    +0x00  dword 总页数（1 基）
    +0x04  →  文本缓冲（首 dword = 0 基当前页数）
当前页数(1基) = [ [结构+0x04] ] + 1
```

**fallback 地址**（会话级，`1.13c.json` `page_addr` = `0x02CBE36C`）：兼容旧式指针结构（[addr] 指向页索引则解引用 +1；直接 1 基页数则原样）。

> 翻页/重开仓库后结构会重新分配，AOB 结果带进程级缓存，校验失败即重新 AOB（`find_stash_page_addr`）。仓库关闭时清缓存并返回页数 0。

## 4. 物品文本系统（ItemTxt + GetLocaleText）

### 4.1 ItemTxt 表定位（物品基础名）

- 行宽 `ROW = 0x1A8`；TXT id = `dwTxtFileNo` = 码表 id = ItemTxt 行号。
- **AOB 定位**：全内存搜 `"flphax"`（行 0 的 `szFlippyfile` 字段），命中后校验：行 0 `szCode='hax '` 且行 529 `szCode='tsc '` → 表基。
- 行字段：

| 偏移 | 字段 |
|---|---|
| +0x00 | szFlippyfile[32] |
| +0x20 | szInvfile[96] |
| +0x80 | szCode[20] |
| +0xF4 | wLocaleTxtNo（WORD） |
| +0xFC / +0xFD | xsize / ysize（占格宽高） |
| +0x11E | nType |
| +0x12A | fQuest |
| +0x138 | socket |

- 物品名 = `GetLocaleText(wLocaleTxtNo)` → 清洗色码/装饰符（`clean_name`）。
- 缓存：`Py/_tables_cache.json`（进程内 + 文件级，按 `_verify_base` 内容校验，失效重新 AOB）。

### 4.2 GetLocaleText（D2Lang+0x9450）

反汇编确认（1.13c）：

```
D2Lang+0x9450  GetLocaleText(n):
    n >= 0x4E20   → 扩展表 [D2Lang+0x10A84] + 文本数组 [D2Lang+0x10A70]，索引 = n - 0x4E20
    10000 <= n < 20000 → 主表  [D2Lang+0x10A80] + 文本数组 [D2Lang+0x10A6C]，索引 = n - 0x2710
    其余/失败     → 回退表 [D2Lang+0x10A64] + 文本数组 [D2Lang+0x10A68]，索引 = n

D2Lang+0x9050  查表（eax=表结构, edx=索引, 栈参=文本数组）:
    cx = [eax+2]                      索引数组长度（WORD）
    索引 >= 长度 → 用 0x1F4（错误兜底）
    entry = [eax + 索引*2 + 0x15]     索引数组（WORD）→ entry 序号
    entry >= [eax+4]（entry 总数）→ 失败
    entry 区校验：每 entry 17 字节，[entry 区] 首字节 == 1 有效
    eax = [文本数组 + entry*4]        → wchar_t*（UTF-16，含 ÿcX 色码）
```

表结构（`ta`）：
```
+0x02  WORD  索引数组长度
+0x04  DWORD entry 总数
+0x11  DWORD entry 区结束偏移
+0x15  起    WORD 索引数组[索引] = entry 序号
entry 区 = ta + 长度*2 + 0x15 起，每 entry 17 字节，首字节==1 有效
文本指针 = [tb + entry*4]
```

- `locale_text.py` 通过扫描 `D2Lang+0x9450` 代码段的 `mov eax/ecx/edx,[imm32]` 动态提取 6 个分派指针（`p_a64/p_a68/p_a80/p_a6c/p_a84/p_a70`），`special_name.py` 用 D2Lang 模块偏移 `+0x10A64..0x10A84` 直读——两者等价，均不硬编码会话地址。
- 分派规则：`idx<10000 → (0x10A64, 0x10A68)`；`10000-19999 → (0x10A80, 0x10A6C)`；`>=20000 → (0x10A84, 0x10A70)`。

### 4.3 文本清洗（clean_name / clean_locale_name）

- 去 `ÿcX` / `ÿc/` 色码、`＊` 星号装饰、换行。
- 扩展表文本形如 `[MAX:..]\n[自助回收..]\nÿc2中文 English` → 取**最后一行** → 去色码 → 剥离 ` 英文` 后缀（空格 + ASCII 字母）→ 纯中文。

## 5. 全局数据表 sgptDataTables（套装 / 暗金权威表）

### 5.1 定位（1.13c 分支）

```
[ D2Common.dll + 0x99E1C ]  →  sgptDataTables
    +0xC0C  →  pSetsTxt         套装组表
    +0xC10  →  nSets
    +0xC18  →  pSetItemsTxt     套装部件表
    +0xC1C  →  nSetItems（127）
    +0xC24  →  pUniqueItemsTxt  暗金表
    +0xC28  →  nUniqueItems（538）
```

> 来源：d2hackmap `d2ptrs.h:191` `D2VARPTR2(D2COMMON, 0x6FDE9E1C, 0xA33F0+DLLBASE_D2COMMON, DataTables, DWORD)`；1.13c 分支 = `D2Common+0x99E1C`（0x6FDE9E1C − 0x6FD50000）。`D2Common+0xA33F0` 为 1.13d 分支，1.13c 下读出垃圾，**勿用**。

### 5.2 SetItemsTxt（套装部件表）

```
记录 0x1B8/条：
    +0x00  dwIndex
    +0x02  szDesc[32]    英文名（如 "Tancred's Weird"）
    +0x24  wLocaleTxtNo  WORD
    +0x28  szCode[4]
    +0x2C  dwSetIdx
```

### 5.3 UniqueItemsTxt（暗金表）

```
记录 0x14C/条：
    +0x00  dwIndex
    +0x02  szDesc[32]    英文名（如 "Gheed's Fortune"）
    +0x22  wLocaleTxtNo  WORD
    +0x28  szCode[4]
```

> 套装/暗金显示名 = `GetLocaleText(wLocaleTxtNo)`（§4.2）。表地址与会话绑定，运行时经 `D2Common+0x99E1C` 重定位并回写 `special_names.json`。

## 6. 物品码表（物品缩写 ↔ 码）

### 6.1 定位

```
[ D2Common.dll + 0x9FF6C ]  →  表指针
    [0x0] → 表基
    [0x8] → 表地址
```

- 码表**仅进入游戏后**可获取（界面标记为 3 开头四位数时已加载）。
- 条目格式：`物品缩写(8 字节) 物品码(4 字节)` 交替排列，例如 `20303172 0000026B 20303272 00000275`（"r10\0" + 619 …）。
- mod 存在**超过 8 位**的缩写（如 `pr` 前缀 mod 物品），按超长缩写特殊解析（跳过 8 字节继续尝试，避免死循环）。
- 物品码 529 → `tsc`（城镇卷）；679 → `pr1`（mod 物品）等。
- dump 产物：`item_codes.json`（`items[i] = {code, id, name, name_clean}`，716 条）。
- **版本匹配**：游戏启动路径（`Bus.lnk → D2Loader.exe`，保留 `-locale kor` 等参数）作为码表版本匹配项；仅对通过本项目启动的游戏操作。启动时核对对应版本码表是否存在/是否 ≥1 周未更新，按需更新（条件：界面标记 3xxx 或码表可读）。

## 7. D2WIN 控件链

### 7.1 入口

```
[ D2Win.dll + 0x214A0 ]  →  FirstControl
```

### 7.2 Control 结构（D2BS D2Structs.h，1.13c 实测）

| 偏移 | 字段 |
|---|---|
| +0x00 | dwType（01 EDITBOX 02 IMAGE 04 TEXTBOX 05 SCROLLBAR 06 BUTTON 07 LIST 0C ACCOUNTLIST …） |
| +0x08 | dwDisabled |
| +0x0C / +0x10 | pos x / y |
| +0x14 / +0x18 | size x / y |
| +0x34 | 回调（换算模块相对偏移 = 稳定唯一标识 `cb_off`） |
| +0x3C | pNext（链表） |
| +0x44 | unkState（按钮 1=置灰） |
| +0x48 | pFirstText |
| +0x5C | EDITBOX/TEXTBOX 内联 wText[256] |
| +0x64 | BUTTON 内联文本 |

### 7.3 ControlText 结构（size 0x20）

```
+0x00..+0x10  wText[0..4]（5 个 wchar_t*）
+0x1C         pNext
```

文本读取：pFirstText 链优先；链空时内联兜底（BUTTON @+0x64、EDITBOX/TEXTBOX @+0x5C）。内联文本可能分多段（段间 `0x0000` = 换行），双对齐解析取可打印比例最高者；垃圾段（含白名单外字符）跳过。

### 7.4 页面识别（800×600 布局坐标特征）

| 页面 | 特征控件 |
|---|---|
| 主菜单 | BUTTON (264,324) + (264,366) |
| 登录 | EDITBOX (322,342) + (322,396) |
| 难度选择 | BUTTON (264,297) + (264,340) |
| 其他多人 | BUTTON (264,310) + (264,350) |
| 角色选择 | BUTTON (627,572) + (33,572) |
| 角色选择/列表 | 存在 ACCOUNTLIST / LIST |

游戏内判定：`player_off = D2CLIENT+0x11B800` 非 0 且有活动控件 → "游戏内"；否则按上述特征 → 菜单页名。

### 7.5 后台点击（不抢鼠标）

```
AHK LauncherClick(pid, x, y):
    y 偏移 -30（控件坐标 → 客户区坐标，winspy 实测校准）
    PostMessage WM_LBUTTONDOWN(0x0201, MK_LBUTTON) → WM_LBUTTONUP(0x0202)
    lParam = (y<<16) | x
```

## 8. 物品特殊名（套装 / 暗金）

### 8.1 链路

```
物品 ItemData+0x28 dwFileIndex
  quality==5 → SetItemsTxt[dwFileIndex]   （sgptDataTables +0xC18，127 条）
  quality==7 → UniqueItemsTxt[dwFileIndex]（sgptDataTables +0xC24，538 条）
→ 行内 szDesc（英文）
→ 双语池查中文：set_names（765 条 [英文,中文]） / notes（735 条 注释池）
→ 显示 "中文 英文"
```

- 双语池来源：**GetLocaleText(wLocaleTxtNo) 权威中文**（套装 127 条全量、unique 补齐 279 条）+ mod 注释池（`巫师之刺` UTF-8 锚点扫描 "中文 英文" 对）。
- 表地址失效 → 运行时重定位（D2Common+0x99E1C 链路）→ 回写 `special_names.json`。
- 显示颜色：1灰 `#9E9E9E`、2白 `#FFFFFF`、3白粗、4蓝 `#4D9FFF`、5绿 `#3DD68C`、6黄 `#FFD666`、7暗黄 `#D4A017`、8橙 `#FF8C00`。

## 9. 仓库 / 背包整理（面板坐标 + 后台点击）

- 面板基准（客户区第一格左上）：仓库 (538,370)、背包 (857,541)；格步长 29px。
- 物品格子坐标：`UnitAny+0x2C → pInvItem`，`+0x0C=gx`、`+0x10=gy`。
- 移动逻辑：拿起物品 → 点目标格（空格放置 / 有物品交换）→ 放回原格；多格占位物品需"首位移位偏移全部命中"才允许替换；每步读 `pCursorItem` 验证。
- 点击加小范围偏移扰动 + 0.1-0.3s 间隔扰动 + 鼠标轨迹模拟（`_human.py`）。
- 后台执行：PostMessage（§7.5），不抢用户鼠标。
