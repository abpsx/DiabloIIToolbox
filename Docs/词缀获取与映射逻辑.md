# 词缀获取与映射逻辑

> 目标：从内存读取魔法/稀有/手工物品的词缀 id，并映射为词缀名（英文/中文）与词条（属性）。
> 适用范围：暗黑2原版 1.13c（D2Loader.exe + anhei2mapBUS mod，-locale kor），只读不写不注入。
> 更新日期：2026-09-11

---

## 1. 词缀槽位布局（物品结构内）

每个物品的 ItemData（idat）中，**连续 6 个 WORD** 存放词缀 id：

```
idat + 0x38  槽0（前缀1）
idat + 0x3A  槽1（前缀2）
idat + 0x3C  槽2（前缀3）
idat + 0x3E  槽3（后缀1）
idat + 0x40  槽4（后缀2）
idat + 0x42  槽5（后缀3）
```

- **布局规则：3 前 3 后**。槽0-2 = 前缀（prefix），槽3-5 = 后缀（suffix）。
- 值为 0 = 该槽无词缀（空）。实际词条数 = 非零槽数。
- 验证实例（三条项链）：
  - 项链1：`985 1312 1051 | 742` = 3前1后，4 词条
  - 项链2：`1326 1055 1121 | 117 374` = 3前2后，5 词条
  - 项链3：`1055 0 0 | 744 118 363` = 1前3后，4 词条

### 物品遍历链路（找 idat）

```
pInv      = *[D2Client+0x11B800 + 0x60]
pFirstItem= *[pInv + 0x0C]              ; 第一件物品
cur       = pFirstItem                  ; unit 结构（物品单元）
循环:
  txt     = word[cur + 0x04]            ; 物品码（520=项链 amu / 522=戒指 rin）
  idat    = *[cur + 0x14]               ; ItemData 结构
  词缀槽  = idat + 0x38 起 6 WORD
  next    = *[idat + 0x64]              ; 下一件物品
```

## 2. 词缀 id → 词缀实体（核心映射）

**id = 扩展表行号**（重要修正：早期误用"id=行号+2"，全错，已废弃）。

- 扩展表（词缀总表，prefix/suffix 混排）：
  - 表地址：`[D2Common + 0x9FBBC]`（会话实测 0x1244DFCC，重启后现取）
  - 行数：`[D2Common + 0x9FBB8]`（会话实测 1452）
  - 行宽：`0x90` 字节
  - 行首：name（ASCII，`\0` 结尾）
- **词缀 id = 行号**（0-1451 有效；id 0 通常不用于物品槽）
- 验证锚点（用户实测权威）：
  - 行 985 = `Iron`（铁之）= 准确率 att
  - 行 1312 = `Monk's`（僧人之）= 圣骑士技能 pal
  - 行 1051 = `Snake's`（蛇之）= 法力 mana
  - 行 742 = `of the Locust`（蝗虫的）= 生命偷取 lifesteal

### 行内结构（关键字段，0x90 行宽内）

| 偏移 | 字段 | 说明 |
|---|---|---|
| +0x00 | name | 词缀英文名，`\0` 结尾（"of " 开头 = 后缀，否则前缀） |
| +0x24 | level | 词缀等级 |
| +0x2C | mod min | 词条数值下限 |
| +0x30 | mod max | 词条数值上限 |
| +0x5C | stat 枚举 | 词条属性枚举（词缀系统自有编号，非 ItemStatCost id） |
| +0x58 | param | 辅助参数（技能类词缀的技能参数等，语义未完全解析） |

**词条数据（stat/min/max/level）全部从内存行读取**——不依赖 txt。
若 mod 删改词缀表（增删行/改名/改数值），内存行即最新状态。

## 3. 中文名获取（名池）

词缀中文名在 tbl 全量字符串池中，UTF-8 `英文\0中文\0` 交错存储：

- 会话地址：`0x12801ACC` 起（tbl 全量池，含词缀名/套装名/暗金名/怪物名/UI 文本）
- anhei 前缀池：`0x12804000` 区（如 BloodUM→鲜血之）
- 原版前缀池：`0x127FEAC5`（如 Emerald→祖母绿之）
- 后缀池：`0x1345118A`（如 of Inertia→惯性的）

扫描方式：按 `ASCII字符串\0 中文字符串\0` 模式解析，建立 `en -> zh` 字典。
注意：该池是 tbl 全量池，非词缀专用，命中需按词缀名精确匹配。

## 4. 词条（mod 属性）——内存 stat 枚举（不再依赖 txt）

词条属性来自扩展表行 +0x5C 的 **stat 枚举**（词缀系统自有编号），验证锚点：

| stat 枚举 | 词条 | 验证词缀 |
|---|---|---|
| 27 | 生命偷取 | of the Locust / 所有 lifesteal 词缀 |
| 28 | 法力偷取 | of the Bat / of the Vampire |
| 110 | 准确率 | Iron |
| 115 | 法力 | Snake's |
| 125 | 职业技能 | Monk's(圣骑士) / Slayer's(野蛮人) ——系别靠 name 特例 |
| 31 | 力量 | of the Giant |
| 1 | 伤害减少/生命 | of Life Everlasting / of Life |

**stat 枚举 → 中文词条映射表**：`temp\dict_magic_stat.json`（由 txt 交叉标注一次性生成，
运行时不依赖 txt）。技能系（125）与抗性系（117 等）的具体细分用词缀名特例细化
（如 Monk's→圣骑士技能、Garnet→火焰抗性）。

### txt 模板（仅作参考/标签，非数据源）

## 5. 已知限制（重要）

1. **具体数值（roll 值）不可从物品内存读取**：
   - 实测扫描 idat/cur ±0x400 无具体数值（如项链1 的 2/19/2/4 不存在物品结构中）
   - 词缀槽 +0x44 起全 0，不存储实例化数值
   - 蓝装词缀数值由 mod 运行时计算（GetItemMagicalMods 在 1.13c 进程全 0 不可用）
2. **扩展表行数值 = 词缀表加载值，与 mod 显示值可能不同**：
   - 实测：Iron att 21-40（表值）vs 游戏内显示 10-30（mod 覆盖）——anhei mod 在数值计算层覆盖
   - 词缀**存在性/名称/结构**以内存表为准；**显示数值**受 mod 计算影响
3. **"鲜血之/螺旋"类词条**：属物品特殊名（tbl 侧），不在词缀 id 槽内，需另查。

## 6. 映射产物

`temp\dict_magic_affixes.json`（1414 条，id 0-1451，**数据源 = 内存扩展表行**）：

```json
{
  "985": {
    "row": 985,
    "name": "Iron",
    "name_zh": "铁之",
    "type": "P",
    "level": 15,
    "stat": 110,
    "mod": {"zh": "准确率", "code": "att", "min": 21, "max": 40}
  }
}
```

- `type`：P=前缀（name 非 "of " 开头）、S=后缀
- `level`：词缀等级（内存行 +0x24）
- `stat`：词条属性枚举（内存行 +0x5C）
- `mod`：词条（zh 中文 / code mod code / min-max 数值范围，全部内存行读取）
- 配套 `temp\dict_magic_stat.json`：stat 枚举→中文映射表（txt 一次性标注，运行时不依赖 txt）
- 旧文件 `dict_magic_prefix.json` / `dict_magic_suffix.json`（txt 源 + id=行号+2 版）已废弃

## 8. 快速使用示例（伪代码）

```python
sP = read_ptr(D2Common_base + 0x9FBBC)          # 扩展表（内存词缀源）
# 读项链1 词缀
words = [read_word(idat + 0x38 + i*2) for i in range(6)]
for i, iid in enumerate(words):
    if not iid:
        continue
    b = sP + iid * 0x90
    name = read_str(b)                            # 词缀英文名（内存）
    typ = "S" if name.startswith("of ") else "P"
    zh = en2zh.get(name, "")                      # 名池中文（内存）
    mod_zh  = stat_zh[w(b+0x5C)]                  # 词条中文（stat 枚举映射）
    mod_min = w(b+0x2C); mod_max = w(b+0x30)      # 数值范围（内存）
```
