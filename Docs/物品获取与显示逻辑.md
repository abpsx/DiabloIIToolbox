# 物品获取与显示逻辑

> 对应代码：`Py\mem_read.py`（`read_bag` 系列）、`Gui\src\views\launcher.vue`（`itemLabel` / `qualityColor`）
> 适用范围：暗黑2 原版 1.13c（D2Loader.exe，anhei2mapBUS mod `-locale kor`）
> 数据来源：CE 实测、d2hackmap 1.13c 源码、GetLocaleText 反汇编
> 最后更新：2026-09-11

---

## 1. 总体流程

```
背包容器 pInv（印章校验 0x01020304）
  └─ [pInv+0x0C] → pFirstItem
       └─ 循环 cur（UnitAny 物品节点，直到 next=0 或节点重复）
            ├─ 取字段：txt 码表id / idat 物品数据 / quality 品质 / dfi 文件索引 / 位置
            ├─ 品质分支：
            │    ├─ ==5 套装 → setitems 表[dfi] → desc → dict_notes[desc] 中文 → special
            │    ├─ ==7 暗金 → uniqueitems 表[dfi] → desc → dict_notes[desc] 中文 → special
            │    └─ 其他     → special = ""
            ├─ 基础名 name = GetLocaleText(wLocaleTxtNo)
            └─ 输出条目 {abbr, code, name, special, quality, loc, slots}
前端显示：text = special / name（都空回退 abbr），按 quality 上色，\n → <br>
```

---

## 2. 每件物品的内存字段

| 偏移 | 字段 | 说明 |
|---|---|---|
| `cur + 0x04` | txt | 物品码表 id（dwTxtFileNo），经 `item_codes.json` 查缩写 |
| `cur + 0x14` | idat | **pItemData 指针**（物品数据结构入口） |
| `idat + 0x00` | quality | 品质（1-8），**特殊名分支的唯一依据** |
| `idat + 0x28` | dfi | dwFileIndex，quality==5/7 时索引对应特殊名表行号 |
| `idat + 0x69` | loc69 | nLocation：2 腰带 / 3 装备 |
| `idat + 0x45` | loc45 | nItemLocation：0 背包 / 3 盒子 / 4 仓库 |
| `idat + 0x64` | next | pNextInvItem，链表下一节点 |

> 注意：**"物品指针 +0x14"是解引用拿 pItemData**，品质本身在 `pItemData + 0x00`，不是 +0x14 直接读。

## 3. 位置判定（loc）

```
loc69 == 2  → loc=2 腰带
loc69 == 3  → loc=3 装备
loc45 == 0  → loc=1 背包
loc45 == 4  → loc=4 仓库
loc45 == 3  → loc=5 盒子
其他        → loc=0 地面/未知（兜底）
```

## 4. 品质分支与特殊名

### 4.1 品质含义（qualityColor）

| quality | 含义 | 颜色 | 前端效果 |
|---|---|---|---|
| 1 | 劣质 | `#9E9E9E` 灰 | 普通 |
| 2 | 普通 | `#FFFFFF` 白 | 普通 |
| 3 | 超强 | `#FFFFFF` 白 | **加粗** `font-weight:600` |
| 4 | 魔法 | `#4D9FFF` 蓝 | 普通 |
| 5 | 套装 | `#3DD68C` 绿 | 普通 |
| 6 | 稀有 | `#FFD666` 黄 | 普通 |
| 7 | 暗金 | `#D4A017` 暗黄 | 普通 |
| 8 | 手工 | `#FF8C00` 橙 | 普通 |
| 其他/未知 | — | 无色 | 不染色 |

### 4.2 套装（quality==5）

```
dfi = [idat+0x28]
setitems 表[dfi] → {code, set_idx, desc, wloc}
special = dict_notes[desc] 有值 ? "中文 英文" : 英文原文
```

- setitems 表：`sgptDataTables + 0xC18`（pSetItemsTxt，127 条），行号直接索引
- set_idx 为套装组索引，wloc 为文本表号（定位/校验用）

### 4.3 暗金（quality==7）

```
dfi = [idat+0x28]
uniqueitems 表[dfi] → {code, desc, wloc}
special = dict_notes[desc] 有值 ? "中文 英文" : 英文原文
```

- uniqueitems 表：`sgptDataTables + 0xC24`（pUniqueItemsTxt，538 条），行号直接索引
- **按 dwFileIndex 行号索引，避免同 code 多暗金误配**（如 cm3 有 Nethercrow / Gheed's Fortune）

### 4.4 其他品质

`special = ""`，仅显示基础名。

## 5. 中文反查与回退链

- **中文唯一入口 `dict_notes`**（en→zh，1174 条）：set/unique 的 desc 均可在其中反查（实测 127/127 + 372/372 全覆盖）
- desc 不在 dict_notes → 回退显示英文原文（不空）
- 特殊名表缺失 / dfi 越界 / 会话级地址失效 → 经 `D2Common+0x99E1C` 链路重定位（+0xC18 套装 / +0xC24 暗金）并回写 `special_names.json` → 仍失败则 `special=""`（只显示基础名/缩写）

## 6. 前端显示（launcher.vue）

```
itemLabel(b, asHtml)：
  parts = [b.special, b.name]（过滤空）
  text = parts.join(" / ") 或回退 b.abbr
  asHtml 时：
    颜色 = qualityColor(b.quality)
    q==3 加粗
    \n → <br>（mod 多行文本：星号装饰行/描述+名字）
    HTML 转义（& < > " '）
```

## 7. 多格物品

- 同一物品占多格时，多个格子指针指向**同一物品结构** → 内存读取层将相同物品的格子索引合并为 `slots: [idx, ...]`（视为一个物品显示）

## 8. 闭环 / 兜底清单

| 场景 | 兜底 |
|---|---|
| 背包未打开/未进游戏 | 印章校验失败 → 返回空列表 |
| 码表 id 查不到缩写 | `abbr = "<txt>"` |
| special 为空 | 只用基础名 |
| name 也为空 | 回退 abbr |
| desc 不在 dict_notes | 显示英文原文 |
| 特殊名表缺失/越界 | 重定位 → 仍失败 special="" |
| 品质未知 | 不染色（default） |
| 位置无法判定 | loc=0 地面/未知 |

## 9. 数据源现状与切换说明

- **当前运行时**：`_set_lookup` / `_sn_lookup` 读取 `Setting\memory\special_names.json` 中的 `set_items` / `unique_items` / `set_names` / `notes`（源数据，会话级地址 + 缓存表）
- **查询字典族**（`temp\dict_set_items.json` / `dict_unique_items.json` / `dict_notes.json`）由 `Py\gen_dicts.py` 从源数据生成，**内容同源**，目前未接入显示运行时
- 如需统一走字典族：`_set_lookup` / `_sn_lookup` 改为优先读 temp 字典（`dict_notes[desc]` 反查中文），失败再回退源数据/内存重定位即可—— 逻辑不变，仅数据源切换
